# Atelier contes

Production des contes africains animés (papier découpé, marionnettes Blender).

- `blender/` : scripts Blender (marionnettes et scènes construites par code)
- `assets/decors/` : décors illustrés
- `.github/workflows/rendu-blender.yml` : rendu réparti sur plusieurs machines GitHub Actions
  (Actions > Rendu Blender > Run workflow). Chaque tranche produit un MP4 téléchargeable.
